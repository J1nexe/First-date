# First Date Planner 💝

A fun web app that helps you plan the perfect first date! Simply answer "Yes" to the date proposal, pick a date from the calendar, choose some fun activities, and select a restaurant. All your date plans are saved so you can look back at them later.

## What Can You Do?

- Get a cute date proposal with a playful "No" button that runs away 😄
- Pick a date using a heart-filled calendar ❤️
- Choose from fun activities like:
  - Going to the arcade 🎮
  - Having a picnic 🧺
  - Watching a movie 🎬
  - Playing board games 🎲
  - Cooking together 👩‍🍳
  - And more!
- Select from popular restaurants like Jollibee, McDonald's, KFC, and others 🍔

## How to Set It Up

1. Install XAMPP or any similar local web server
2. Copy all files to your web server folder
3. Create the database:
   - Open phpMyAdmin
   - Create a new database called `date_planner`
   - Import the `create_database.sql` file

## Files You'll Find

- `index.html` - The cute date proposal page
- `calendar.html` - Pick your date here
- `activities.html` - Choose fun activities
- `restaurants.html` - Select where to eat
- `view_date_plans.php` - See all your planned dates
